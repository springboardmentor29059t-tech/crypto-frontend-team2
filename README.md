# **CRYPTO PORTFOLIO TRACKER WITH RISK & SCAM ANALYSIS**

**A Full-Stack Cryptocurrency Portfolio, Analytics & Risk Intelligence Platform**

---

## 📌 Overview

The **Crypto Portfolio Tracker** is a complete **full-stack cryptocurrency tracking and analytics platform** built using **React (Vite + TypeScript)** for the frontend and **Spring Boot** for the backend, with **PostgreSQL** as the database.

This application enables users to **track crypto assets**, analyze **profits & losses**, calculate **tax implications**, monitor **market sentiment**, detect **scams**, and gain **risk insights** using real-time data.

The platform is designed to be:

* 🔐 Secure
* ⚡ Scalable
* 📊 Data-driven
* 🎯 User-friendly

It is ideal for **investors, learners, and demo presentations**.

---

## 🖥️ Tech Stack

### Frontend

* React (Vite)
* TypeScript
* Tailwind CSS
* Axios
* Context API
* Charting Libraries (for analytics)

### Backend

* Spring Boot
* RESTful APIs
* JWT-based Authentication
* Role-Based Access Control

### Database

* PostgreSQL

### Deployment

* Frontend: **Vercel**
* Backend: **Render / Railway / Localhost**
* Database: **PostgreSQL (Cloud / Local)**
